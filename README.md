# Media Data Platform

> **Projet en cours de mise à jour.** Une nouvelle version, entièrement sur BigQuery, est en préparation. Le code sera publié ici à l'issue de cette mise à jour.

## Le sujet

Une agence marketing gère des campagnes publicitaires sur Meta Ads et sur Google Ads. Chaque plateforme livre ses données dans son propre format : noms de colonnes différents, indicateurs calculés différemment. Comparer les deux plateformes sur les mêmes campagnes et les mêmes dates devient impossible.

**L'objectif :** réunir les deux sources dans une seule table analytique fiable, avec une définition unique de chaque indicateur (CTR, CPC, CPA, taux de conversion, ROAS), testée et documentée.

## La mise à jour en cours

- Exécution de bout en bout sur Google Cloud et BigQuery.
- Transformations et tests avec dbt Core.
- Nouvelles captures et documentation.
